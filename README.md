# Orbis Engine

A Dart-first 3D game engine. Game logic and UI in Flutter, a C++ ECS core and
Google's [Filament](https://github.com/google/filament) renderer underneath.

Pre-alpha. `./spike/build.sh` renders a frame.

MIT. Portions derive from [flutter_scene](https://github.com/bdero/flutter_scene)
by Brandon DeRosier, used under the same licence.
