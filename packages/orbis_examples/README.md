# orbis_examples

One technique at a time: a scene that shows it, the controls that change it,
and the lines that do it. Shown by the gallery app and by the editor.

Part of [Orbis](https://github.com/Orbis-Engine/orbis), a Dart-first 3D game
engine. The documentation is at [the Orbis documentation]().

## Using it

```yaml
dependencies:
  orbis_examples:
    git:
      url: https://github.com/Orbis-Engine/orbis.git
      path: packages/orbis_examples
```

Needs Flutter. Runs anywhere Flutter runs.

## Status
