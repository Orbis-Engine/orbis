# orbis_light

Lights described the way an artist states them — watts, metres and degrees —
and converted to the photometric units a renderer works in.

Part of [Orbis](https://github.com/Orbis-Engine/orbis), a Dart-first 3D game
engine. The documentation is at [orbisengine.dev](https://orbisengine.dev).

## Using it

```yaml
dependencies:
  orbis_light:
    git:
      url: https://github.com/Orbis-Engine/orbis.git
      path: packages/orbis_light
```

Needs Dart alone. Runs anywhere Dart runs, including a headless CI runner.
